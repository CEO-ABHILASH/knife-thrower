# Knife Thrower - Arcade Master

An interactive, responsive arcade web game built with vanilla HTML, CSS, and modern JavaScript.

## Features
- Dynamic collision detection and knife physics
- Combo multiplier alerts and streak system
- Boss encounter stages with custom animations
- Procedural rendering effects and responsive HUD
- Local best score tracking

## Getting Started
Open `index.html` in any modern web browser or serve it using a local HTTP server.
